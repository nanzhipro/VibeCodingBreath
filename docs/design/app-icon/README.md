# VibeCodingBreath App Icon Exploration

This folder contains prompt variants and generated candidates for the macOS app icon.

Design constraints used for this exploration:

- Built around the product idea: "AI 在思考时，你在呼吸"
- Optimized for a macOS app icon, not a marketing illustration
- Meant to feel native to Apple platforms: restrained, calm, dimensional, recognizable
- Avoids text, code snippets, mascots, literal lungs, and over-detailed scenes
- Uses the product's existing blue family as a starting point

Source inputs:

- `docs/PRD.md`
- Apple Human Interface Guidelines: App Icons
- Apple Developer docs: Icon Composer / asset catalog app icons

Expected output:

- 1:1 master icon candidates
- one recommended final candidate to convert into `.icns` later
