Create a distinctive macOS app icon for VibeCodingBreath.

Intent:
Express breath, flow, patience, and concentration for an ultra-minimal menu bar app that appears while the user waits for AI results.

Symbol concept:
- a single flowing loop or ring made from soft air-like bands
- the loop should imply inhale and exhale motion without looking like an infinity logo
- the shape should feel balanced, centered, and easy to recognize

Look and feel:
- strongly aligned with Apple's app icon taste
- calm, premium, minimal, modern
- uses restrained depth
- subtle glass-like layering
- clean edges and a memorable center form
- color palette anchored in soft cyan blue, pale cloud white, and deep desaturated teal

Composition requirements:
- 1:1 macOS app icon master
- central symbol with generous negative space
- no text or extra UI objects
- no mockup frame
- the icon should still work when reduced in size

Avoid:
- obvious wind glyph copies
- swirls that feel generic
- hard-edged tech logos
- too many internal details
- strong outer shadows
- noisy backgrounds

The icon should feel thoughtful and native, like a real Apple-platform utility icon rather than a startup logo.
