Design a premium macOS app icon for an app named VibeCodingBreath.

Concept:
A calm breathing halo for developers waiting while AI works. The icon should communicate breath, focus, stillness, air, and gentle rhythm.

Visual direction:
- Apple-native app icon aesthetic
- minimal, refined, instantly recognizable
- a single centered symbol
- clean silhouette that still reads at small sizes
- layered depth with subtle glass-like translucency
- soft cyan-blue palette inspired by #7FB3D5 with cool mist, silver-blue, and deep blue accents
- elegant negative space
- polished but restrained, not loud

Primary motif:
- a luminous circular orb or ring with one or two subtle concentric breathing waves
- the form should feel like inhale/exhale, as if the circle is quietly expanding
- emphasize serenity and focus more than energy

Composition:
- square macOS app icon master artwork
- centered composition
- rounded-square icon composition feeling, but no external device mockup
- simple background field with subtle depth
- no scene, no desk, no window UI, no text

Style rules:
- native Apple design language
- high clarity
- limited palette
- smooth materials
- dimensional but not busy
- refined gradients
- no heavy shadows
- no exaggerated glow bloom
- no cartoon style
- no photoreal subject

Avoid:
- letters or typography
- lungs, people, faces, hands
- code brackets, terminal windows, keyboards
- generic meditation clichés
- complicated multi-object composition
- brand/logo similarity to existing major apps

Output goal:
Create a final icon candidate that feels like it belongs on macOS alongside Apple-designed apps.
